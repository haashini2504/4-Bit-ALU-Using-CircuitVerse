# 4-Bit ALU Design and Simulation using CircuitVerse

## Project Overview
This project focuses on the design and simulation of a 4-bit Arithmetic Logic Unit (ALU) using CircuitVerse.

The ALU performs arithmetic and logical operations using digital logic circuits and a multiplexer-based selection mechanism.

## Tools Used
- CircuitVerse
- Digital Electronics
- Combinational Logic Design

## ALU Features
- 4-bit binary addition
- 4-bit binary subtraction
- Bitwise AND
- Bitwise OR
- Bitwise XOR
- Bitwise NOT A
- Bitwise NOT B
- Zero output

## Test Results

Test inputs:
- A = 0101
- B = 0011

| Selection | Operation    | Output |
|---        |---           |---     |
| 000       | Addition     | 1000   |
| 001       | Subtraction  | 0010   |
| 010       | AND          | 0001   |
| 011       | OR           | 0111   |
| 100       | XOR          | 0110   |
| 101       | NOT A        | 1010   |
| 110       | NOT B        | 1100   |
| 111       | Zero output  | 0000   |
